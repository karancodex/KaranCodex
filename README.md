# 🚀 Karan Codex - Software Company Website

This is a modern, responsive website for a software company, SaaS product, or tech startup built using **Next.js**, **Tailwind CSS**, and **TypeScript**. It includes pages like Home, About, Services, Contact, and more.

## 🖥️ Live Demo

👉 [View Live Website](https://karan-codex.vercel.app/)

## 📁 Project Structure

. ├── public/ # Static assets ├── src/ │ ├── app/ # App directory (Next.js 15+) │ ├── components/ # Reusable UI components │ ├── styles/ # Global styles and Tailwind config │ └── utils/ # Utilities and helpers ├── tailwind.config.js # Tailwind CSS config ├── postcss.config.js # PostCSS config ├── tsconfig.json # TypeScript config └── README.md

## 🔧 Tech Stack

- **Framework**: Next.js 15+ (App Router)
- **Styling**: Tailwind CSS
- **Type Checking**: TypeScript
- **Form Handling**: Formik + Yup
- **Deployment**: Vercel / Netlify


## 🧪 Features

- ⚡ Fast performance with SSR
- 📱 Fully responsive for all screen sizes
- 🧩 Modular components and layout
- 🌓 Light/Dark mode support
- 📬 Working contact form (Formspree or custom API)
- 💬 Testimonials, Pricing, FAQs, and more


## 🚀 Getting Started

### 1. Clone the repo
git clone https://github.com/karancodex/KaranCodex.git

cd your-project

### 2. Install dependencies

npm install

or

yarn install

### 3. Run the development server

npm run dev

or

yarn dev

Visit http://localhost:3000 in your browser.

🔒 Environment Variables
Create a .env.local file and add any necessary environment variables:
env

NEXT_PUBLIC_FORM_ENDPOINT=https://formspree.io/f/your-form-id
🛠 Deployment
Deploy easily on Vercel, Netlify, or any Node.js host.
Vercel: https://vercel.com/new
